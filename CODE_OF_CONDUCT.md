# Code of Conduct

## 1. Purpose

The purpose of this Code of Conduct is to define the standards expected from contributors, maintainers, and users participating in the Nexo Finance project.

We want project discussions, issues, pull requests, reviews, and support interactions to remain respectful, focused, and productive.

By participating in this project, you agree to follow this Code of Conduct.

---

## 2. Scope

This Code of Conduct applies to all project spaces, including but not limited to:

- GitHub issues
- Pull requests
- Code reviews
- Discussions
- Documentation contributions
- Support-related public communication
- Any other official project collaboration space

Private security reports are handled separately through the process described in [SECURITY.md](./SECURITY.md).

---

## 3. Expected Behavior

Participants are expected to:

- Be respectful and professional
- Provide constructive feedback
- Stay focused on the issue, pull request, or topic being discussed
- Ask questions clearly
- Accept reasonable technical disagreement
- Avoid personal attacks
- Respect project maintainers' decisions
- Protect private information and sensitive data

---

## 4. Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, intimidation, or discrimination
- Personal attacks, insults, or hostile comments
- Offensive, sexual, violent, or inappropriate content
- Trolling, spam, or repeated off-topic comments
- Publishing private information without permission
- Sharing secrets, tokens, API keys, or private financial data
- Abusing public issues for security reports
- Attempting to pressure maintainers into unsafe changes

---

## 5. Reporting

If you see behavior that violates this Code of Conduct, report it to the project maintainers through the most appropriate private channel available.

For security-related issues, do not use public issues. Follow the process in:

- [SECURITY.md](./SECURITY.md)

For normal project issues that do not include sensitive information, use GitHub Issues.

---

## 6. Enforcement

Project maintainers may take action when this Code of Conduct is violated.

Possible actions include:

- Asking for edits or clarification
- Removing inappropriate content
- Closing or locking issues or pull requests
- Blocking repeated disruptive behavior
- Restricting participation in project spaces

Enforcement decisions are made to protect the project, its users, and its maintainers.

---

## 7. Maintainer Responsibility

Maintainers are responsible for keeping project communication clear, safe, and productive.

Maintainers should apply this Code of Conduct consistently and avoid using it to silence reasonable technical disagreement.

---

## 8. Acknowledgements

This Code of Conduct is inspired by common open-source community standards, including the Contributor Covenant, and adapted for the needs of Nexo Finance.
